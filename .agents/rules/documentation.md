# Documentation and screenshots

- Update the relevant README or `docs/` pages whenever behavior, setup, data handling, privacy, limitations, or user workflows change.
- Keep README claims, architecture, product guides, privacy guidance, roadmap, and UI behavior consistent.
- Update `docs/showcase/README.md` and relevant screenshots when a UI workflow changes. Use synthetic data only; never capture real profile details, tokens, or provider responses.
- Label screenshots that are stale or illustrative. Do not claim a screenshot proves behavior it does not show.
- Keep documentation links valid and add new guides to `docs/README.md`.
