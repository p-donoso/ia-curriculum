# Internationalization

- Keep Spanish and English interfaces in sync in `app/i18n.tsx` whenever user-facing text changes.
- Use translation keys for visible labels, messages, accessible names, and confirmations; do not hardcode one-language UI copy in components.
- Keep stored field keys and data stable across locales; translate labels at the UI boundary with `lib/profiles/field-labels.ts`.
- Check both languages for length, clarity, and grammatical agreement.
- Update localization-related tests when translation behavior or labels change.
