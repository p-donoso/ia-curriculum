# Product roadmap

## Current scope

- [x] Multiple browser-local profiles with isolated answers and records.
- [x] Guided reflection with bounded answers and a completion state.
- [x] Editable education, experience, project, and skill records.
- [x] Optional BYOT streaming for OpenAI-compatible chat-completions APIs.
- [x] Reviewable, schema-limited AI proposals.
- [x] Profile JSON export and local profile-data deletion.
- [x] Responsive profile navigation and printable English CV view.

## Next

- [ ] Persist reflection sessions separately from profile metadata.
- [ ] Make LinkedIn output a complete editable draft.
- [ ] Add accessible CV layouts and language variants.
- [ ] Add robust import with validation and conflict handling.
- [ ] Add automated coverage for key user-facing flows and browser storage failure cases.

## Principles

Suggestions never become facts without review. Templates operate on confirmed records. Privacy and data controls are core product behavior.
